## Development environment

[devenv](https://devenv.sh/) is used to declare and set up a development environment. devenv will bootstrap everything that is needed for development

1. Download and install [nix](https://nixos.org/), the package manager, if needed.
2. Enter in terminal: `nix profile install nixpkgs#devenv`
3. Enter `devenv shell`
