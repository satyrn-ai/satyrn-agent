# devenv macOS 26 SDK — evidence, 2026-11-21

`devenv.nix` pinned `apple.sdk` to `pkgs.apple-sdk_15` when the ds4 source only needed macOS 15 Metal
APIs. The source now also carries a macOS 26 Metal 4 path, and the 15 SDK hides it: the tensor probe
and `ds4_gpu_detect_metal4_features()` are compiled out under `#if __MAC_OS_X_VERSION_MAX_ALLOWED >=
260000`, so `tensor_matmul` reports off and prefill runs about 43% below a 26-SDK build. The pinned
nixpkgs already provides `pkgs.apple-sdk_26`; this is a one-line change.
